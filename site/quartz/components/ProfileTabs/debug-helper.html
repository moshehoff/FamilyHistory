🐛 Debug Console API

Available in browser console when ProfileTabs is loaded:

__profileTabs.setDebug(true)
Enable debug logging
await __profileTabs.getState()
Get current state
__profileTabs.reinit()
Force reinitialize
__profileTabs.logger.printStats()
Show log statistics
__profileTabs.stateManager.logState()
Show current state details
__profileTabs.eventManager.logStats()
Show active event listeners
